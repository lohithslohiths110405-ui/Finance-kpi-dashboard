# Finance KPI Dashboard

## Project Overview

The Finance KPI Dashboard is an interactive Business Intelligence project developed using Power BI. It helps organizations monitor financial performance by comparing budgeted and actual expenses, analyzing budget utilization, identifying overspending, and tracking financial variations across departments, regions, and expense categories.

## Project Objectives

- Monitor total budget and actual expenditure.
- Analyze budget variance and overspending.
- Compare financial performance across departments and regions.
- Track monthly and yearly expenditure trends.
- Identify major expense categories.
- Support data-driven financial planning and decision-making.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## Key Performance Indicators (KPIs)

| KPI | Value |
|---|---:|
| Total Budget | 796M |

| Budget Utilization | 111.94% |
| Overspending | 11.94% |

## Key Business Insights

- Actual expenditure exceeds the allocated budget by approximately 95M.
- Overall budget utilization is 111.94%.
- The organization has an overall overspending rate of 11.94%.
- Utilities and Travel are among the major expense categories.
- Department-wise analysis helps identify areas exceeding allocated budgets.
- Monthly and yearly comparisons support better financial planning.
